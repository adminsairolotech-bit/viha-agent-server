# VihaAgent Storage

Ye folder D: drive par hai - ye aapke laptop ki permanent storage hai.

## Kya store kar sakte ho:
- Agent memory/context files
- Project files jo cloud par nahi hain
- Personal notes aur logs
- Temporary files

## Benefits:
1. Laptop band bhi ho - files safe rahegi
2. D: drive se files quickly access kar sakte ho
3. Railway server par deploy kar sakte ho directly

## Usage with Claude Code:
Claude Code ise directly is folder se kaam kar sakta hai.
